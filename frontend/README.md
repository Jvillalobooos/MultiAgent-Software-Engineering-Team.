## Getting Started

From the repository root, start the existing FastAPI application:

```powershell
.\.venv\Scripts\python.exe -m uvicorn sample_app.app.main:app --host 127.0.0.1 --port 8000
```

Then, in `frontend/`:

1. Run `npm install`
2. Run `npm run dev`

Vite proxies `/api` and `/ws` to that application. Runs execute in isolated
workspace copies through the repository's production LangGraph workflow.
